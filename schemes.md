# App URL schemes

App URL schemes now appear with each platform's other links, under **App links**, at [nathangathright.github.io/podcast-platform-links](https://nathangathright.github.io/podcast-platform-links/). Filter the list by **App links** to see every scheme.

The same data is available as [`platforms.json`](https://nathangathright.github.io/podcast-platform-links/platforms.json).
